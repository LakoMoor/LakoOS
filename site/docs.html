First boot

Start the live ISO. The desktop appears with the taskbar in the center. Open Start to see pinned apps, type to search, or open This PC to browse drives.

Install to a disk

Boot the Setup ISO (LakoOS-amd64-setup.iso) with an empty virtual disk attached. Choose a language, pick Install LakoOS, select the disk and follow the wizard: account, time zone, summary. After the first restart the desktop opens and signs you in automatically when no password is set.

Build the Setup ISO yourself with ./buildenv/build.sh --target bootcd.

Settings

The shell reads these values from HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced. Changes apply the next time you open Start.

ValueDataMeaning
ShellStyle11Centered Start (default)
ShellStyle10List and tiles Start
ShellStyle7Classic two-column Start
TaskbarAl0 / 1Taskbar left / center
reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced /v ShellStyle /t REG_DWORD /d 10 /f
reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced /v TaskbarAl /t REG_DWORD /d 0 /f

Folder layout

System files live in Windows and Windows\System32. Applications go to Program Files and Program Files (x86). Shared data is in ProgramData, and user profiles are under Users.

Build from source

The buildenv folder installs the compilers and tools and builds the image from scratch.

git clone https://github.com/LakoMoor/LakoOS.git
cd LakoOS
./buildenv/build.sh                 # Linux, macOS
.\buildenv\build.ps1                # Windows (WSL2 or -Backend docker)

Options: --arch amd64|i386|arm64, --target livecd|bootcd|reactosimg|reactosvhd, --release, --env-only. The first build needs about 15 GB of free disk.

Getting help

Report problems in GitHub Issues with the architecture, the build type and the steps that lead to the problem.
