Meet LakoOS

A free NT operating system with a familiar desktop: centered Start, a modern File Explorer and the same folders and program names.

Download LakoOSSee what's new

A fresh, familiar desktop

The taskbar sits in the center, Start has a pinned grid and recommendations, and the light theme is the default.

  • Two Start styles: centered grid or list with tiles
  • Light and dark theme
  • Same program names: explorer, taskmgr, cmd

File Explorer, rebuilt

Tabs, a command bar and a folder tree in the navigation pane.

Built for the hardware you have

64-bit first, with the same system on both architectures.

amd64 and arm64

Live and setup images for both, UEFI boot.

Windows apps

64-bit and 32-bit programs run; DirectX 9 to 12 start on a software renderer.

Free software

GNU GPL. Read it, change it, share it.

Get started in three steps

Download

Pick the ISO for amd64 or arm64.

Create a virtual machine

QEMU, VirtualBox or Hyper-V with 2 GB of memory.

Start

Boot the ISO and choose Run or Install.
