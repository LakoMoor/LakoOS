Run it

QEMU

qemu-system-x86_64 -m 2048 -smp 4 \
  -cdrom LakoOS-amd64-livecd.iso -boot d \
  -vga std -usb -device usb-tablet

On Linux add -enable-kvm for speed.

QEMU ARM64

qemu-system-aarch64 -M virt -cpu cortex-a72 -smp 4 -m 3072 \
  -drive if=pflash,format=raw,readonly=on,file=AAVMF_CODE.fd \
  -drive if=pflash,format=raw,file=vars.fd \
  -device ramfb -device qemu-xhci -device usb-kbd -device usb-tablet \
  -drive file=LakoOS-arm64-livecd.iso,if=none,id=cd,media=cdrom \
  -device usb-storage,drive=cd,bootindex=0

VirtualBox

  1. New machine, type Other, version Other/Unknown (64-bit).
  2. 2048 MB of memory, no hard disk needed for the live image.
  3. Attach the ISO to the optical drive and start.

Hyper-V

  1. New virtual machine, Generation 1.
  2. 2048 MB of memory, attach the ISO as a DVD drive.
  3. Start and connect.

Three steps to try LakoOS

①

1. Download

Pick the ISO for your architecture, amd64 or arm64.

②

2. Create a VM

Use QEMU, VirtualBox or Hyper-V with 2 GB of memory.

③

3. Start

Attach the ISO and boot. Choose Install to keep it on a disk.

Questions

Which file should I download?

Use the Live ISO to look around without changing anything. Use the Setup ISO to install to a virtual disk. Pick amd64 for PCs and arm64 for ARM virtual machines.

Can I run it on real hardware?

LakoOS is a development preview. Use a virtual machine for now.

Is it free?

Yes, under the GNU GPL.

Does it run Windows apps?

Many classic Win32 apps run. See the compatibility page for the current status.
