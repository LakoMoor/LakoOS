Build it yourself

One command prepares everything from scratch.

Linux · macOS · Windows
Build instructions

Run it

QEMU

qemu-system-x86_64 -m 2048 -smp 4 \
  -cdrom LakoOS-amd64-livecd.iso -boot d \
  -vga std -usb -device usb-tablet

On Linux add -enable-kvm for speed.

VirtualBox

  1. New machine, type Other, version Other/Unknown (64-bit).
  2. 2048 MB of memory, no hard disk needed for the live image.
  3. Attach the ISO to the optical drive and start.

Hyper-V

  1. New virtual machine, Generation 1.
  2. 2048 MB of memory, attach the ISO as a DVD drive.
  3. Start and connect.
