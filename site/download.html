Install in three steps

Create a machine

2 GB of memory, a 16 GB disk, UEFI.

Attach the setup ISO

Start the machine and pick your language.

Follow the wizard

Choose the disk, name your PC and finish.

System requirements

Processor64-bit x86 or ARM64, 2 cores
Memory2 GB
Storage8 GB for installation
FirmwareUEFI or BIOS (amd64), UEFI (arm64)

Frequently asked questions

Which file should I download?

Use the live image to look around, the setup image to install.

Can I run it on real hardware?

It is a development preview. Use a virtual machine first.

Is it free?

Yes, under the GNU GPL.

Does it run my programs?

Many classic programs do. See the compatibility page.
