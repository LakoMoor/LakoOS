Mobile

A shell made for touch

An experimental phone and tablet style: home screen, large tiles and a navigation bar. Same system, amd64 and arm64.

Home screen

Clock, tiles, search

Large clock and date, rounded colour tiles and a search bar within thumb reach. Scroll by dragging.

  • Wide first tile, two columns in portrait, four in landscape.
  • Navigation bar: Back, Home and Recents.
  • Scales to 250 % for 400 ppi panels.
  • Switch on with ShellStyle=12 or the MOBILE_SHELL build option.

Xiaomi POCO F1

A profile for the Snapdragon 845 phone exists (scaling and shell style). Booting on the phone needs a UEFI image from the edk2-sdm845 project. Storage, touch and graphics drivers are not written yet, so this is a build profile for now.
