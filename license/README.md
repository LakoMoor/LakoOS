# Licenses and origin

LakoOS is free software.

## Origin

LakoOS is based on the **ReactOS** project (https://reactos.org), a free NT-compatible
operating system, through the LiberNT fork (https://github.com/ahmedarif193/LiberNT).
Most of the kernel, drivers, system libraries and applications in this repository come
from ReactOS and keep the copyright and license notices of their authors in the source
file headers. The ReactOS developers are credited in the ReactOS project and in the
file headers; the LiberNT and LakoOS authors are listed in `CREDITS.md`.

ReactOS is a trademark of the ReactOS Project. LakoOS is an independent fork and is not
affiliated with or endorsed by the ReactOS Project.
